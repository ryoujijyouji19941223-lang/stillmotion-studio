# サンプル作品『まると おともだち』

StillMotion Studioの基準作品です。表紙を含む18ページで、v0.1のカメラ・オーバーレイ・音声・書き出しと、v0.2の部分モーションを確認します。

## 構成

```text
sample/maru/
├── 01.webp ... 18.webp   # ページ画像（既存パスを維持）
├── project.json          # 保存・再読込用の作品定義
├── README.md             # この説明
└── audio/
    └── README.md         # 将来追加する音声の置き方
```

画像を `images/` へ移すとv0.1の既存パスが切れるため、現段階では移動しません。将来プロジェクトの素材参照を一括更新できるようになってから移行を判断します。

## 読み込み方

1. リポジトリのルートでローカルサーバーを起動します。
2. StillMotion Studioで「JSON読込」を押します。
3. このフォルダの `project.json` を選びます。

## v0.2での検証候補

| ページ | 候補 | 動き |
| --- | --- | --- |
| 4〜5 | 公園の木・草 | `sway` |
| 9〜11 | 雨の中の枝・傘周辺 | `sway` / `drift` |
| 12 | 右上の木の葉 | `sway`（見本を設定済み） |
| 13〜14 | 森の枝・草 | `sway` |
| 16〜17 | コップ、ナプキン、包み | `drift` |
| 18 | 背景の自然物 | ごく弱い `sway` |

文字とキャラクターの顔は、最初の部分モーション対象にしません。背景の自然物から始め、切り抜き境界と背景の穴が目立たない設定を探します。

## 素材を追加するとき

- ページ画像は2桁の連番を保ちます。
- 音声は `audio/README.md` の命名規則を使います。
- マスクを追加する段階で `masks/` を作り、`NN-region-name.png` の形で保存します。
- 生成途中の動画や大きな一時ファイルはリポジトリへ入れません。
