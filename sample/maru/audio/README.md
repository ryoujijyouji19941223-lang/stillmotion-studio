# 音声素材の置き方

音声とBGMはまだ同梱していません。追加時は用途別に次の名前を使います。

```text
audio/
├── narration/
│   ├── 01.wav
│   └── 02.wav
├── ambient/
│   ├── 09-rain.wav
│   └── 12-wind.wav
├── sfx/
│   └── 16-cup-roll.wav
└── bgm/
    └── main-theme.wav
```

- 元素材は劣化を避けるためWAVを推奨します。
- 試用ページではシーンごとにマイク録音もできます。完成素材として残す場合は「端末へ保存」で音声ファイルを保存し、次回「ナレーション音声ファイル」から読み込んでください。
- 配布サイズを小さくするときは、権利を確認したうえで圧縮版を別途作ります。
- ライセンス、作者、入手元はこのフォルダ内の `CREDITS.md` に記録します。
- ローカル試作だけで使う素材は `local-assets/` に置き、Gitへ追加しません。
