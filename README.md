# StillMotion Studio v0.1

静止画を「フルアニメにせず、小さな動き・読み上げ・効果音・BGMで疑似映像化」するためのローカル試作ツールです。

最初のテスト作品として『まると おともだち』18ページを同梱しています。

## できること

- 複数の静止画をシーンとして並べる
- シーンごとの文章・表示秒数を管理
- カメラのズーム / パン
- **文字保護モード**: 文字入り絵本は画像全体を固定し、雨・風などだけ動かす
- 雨 / 風 / 葉 / 木漏れ日 / 蝶 / 光粒 / 雪 / ほこり
- 文章から表示秒数を簡易推定
- 文章から演出を簡易提案
- ブラウザTTSで読み上げ試聴
- ナレーション音声・環境音をシーンごとにアップロード
- 全体BGMをアップロード
- 雨 / 風は素材がなくても簡易環境音を自動生成
- プロジェクトJSON保存 / 読込
- Chrome / Edgeで WebM 動画を書き出し（音声もミックス）

## Windowsで起動

1. このフォルダを展開
2. `start.bat` をダブルクリック
3. ブラウザで `http://localhost:4173` が開く

Python がPATHに入っていない場合は、コマンドプロンプトで:

```bat
py -m http.server 4173
```

をこのフォルダで実行し、ブラウザで `http://localhost:4173` を開いてください。

## なぜインストール不要なのか

v0.1は依存ライブラリなしのHTML/CSS/JavaScriptだけで動きます。まず「どんな編集が必要か」を実作品で確認するためです。

本格版では、レンダリングを Remotion + FFmpeg に置き換える計画です。v0.1の `project.json` 形式は、そのまま本格版へ移せるようにしてあります。

## 重要な制約

- ブラウザTTSは試聴用です。WebMに確実に入れたい場合は、ナレーション音声ファイルを各シーンに指定してください。
- ローカルで追加した画像・音声ファイル本体はJSONには埋め込まれません。同じセッション内では動画に使えます。
- 現在は「木だけ」「カーテンだけ」のような画像内部の部分選択アニメーションは未実装です。これはv0.2の中心機能です。
- WebM書き出しは実時間です。2分の作品なら約2分かかります。
