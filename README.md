# StillMotion Studio

静止画に、小さな動き・読み上げ・環境音・BGMを重ねて「疑似映像」を作るローカル編集ツールです。フルアニメーションを生成し直すのではなく、元絵の見た目を守りながら必要な部分だけを動かすことを目標にしています。

現在の安定した試作は **v0.1** です。`work/v0.2-partial-motion-prep` ブランチでは、v0.2の中心機能「画像の一部分だけを動かす」のデータ形式・責務・テスト土台を準備しています。

## v0.1でできること

- 複数の静止画をシーンとして並べる
- 文章、表示秒数、カメラのズーム・パンをシーンごとに設定する
- 雨、風、葉、木漏れ日、蝶、光粒、雪、ほこりを重ねる
- 文字入り画像を固定する「文字保護モード」
- ブラウザTTSで読み上げを試聴する
- ナレーション、環境音、全体BGMを読み込む
- プロジェクトをJSONで保存・読込する
- Chrome / Edgeで音声入りWebMを書き出す

## 起動方法

Windowsでは `start.bat` をダブルクリックし、ブラウザで `http://localhost:4173` を開きます。

手動で起動する場合は、このフォルダで次を実行してください。

```bash
python -m http.server 4173
```

Pythonランチャーを使うWindows環境では、次でも起動できます。

```bat
py -m http.server 4173
```

依存ライブラリのインストールは不要です。

`sample/maru/` に、18ページの『まると おともだち』を収録しています。

- `01.webp`〜`18.webp`: ページ画像

- `README.md`: 作品構成と素材追加時の置き場所

既存の画像パスを壊さないため、v0.1の `sample/maru/NN.webp` は移動していません。

## v0.2の準備状況

v0.2では、ユーザーが選んだ領域だけを動かします。現段階では画面からマスクを描く機能はまだ有効化していませんが、次の土台を追加しています。

- `motionRegions` の保存形式
- 揺れ、移動、波、炎、呼吸に対応するモーション種別
- 入力値の正規化と検証
- 時刻からTransform値を求める純粋関数
- 旧v0.1プロジェクトを読み込むための後方互換方針
- Node標準テストによるデータモデル確認

準備コードの確認にはNode.js 20以降で次を実行します。

```bash
npm test
```

詳細は [部分モーション設計](docs/PARTIAL_MOTION.md) と [ロードマップ](docs/ROADMAP.md) を参照してください。

## 現在の制約

- ブラウザTTSは試聴用です。動画へ確実に入れる場合はナレーション音声ファイルを指定してください。
- ローカルで追加した画像・音声の本体はプロジェクトJSONへ埋め込みません。
- WebM書き出しは実時間です。2分の作品なら約2分かかります。
- v0.2のマスク編集、背景の穴埋め、部分変形UIはこれから実装します。

## 開発方針

v0.1は動作する基準として維持します。v0.2の処理はまず `src/v0.2/` で小さく検証し、保存形式と描画結果を固めてから既存UIへ接続します。これにより、試作版を壊さず段階的に置き換えられます。
