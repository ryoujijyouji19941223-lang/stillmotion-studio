# StillMotion Studio

静止画に、小さな動き・読み上げ・環境音・BGMを重ねて「疑似映像」を作るローカル編集ツールです。フルアニメーションを生成し直すのではなく、元絵の見た目を守りながら必要な部分だけを動かすことを目標にしています。

`main` は **v0.1基準版**、`work/v0.2-partial-motion-prep` ブランチは **v0.2プレビュー版** です。プレビュー版では、画像上を四角または自由な輪郭で選び、その範囲だけに小さな動きを付けられます。

## v0.1でできること

- 複数の静止画をシーンとして並べる
- 文章、表示秒数、カメラのズーム・パンをシーンごとに設定する
- 横長画像は「全体を表示」に切り替え、左右を切らずにぼかし背景つきで配置する
- 雨、風、葉、木漏れ日、蝶、光粒、雪、ほこりを重ねる
- 文字入り画像を固定する「文字保護モード」
- ブラウザTTSで読み上げを試聴する
- ナレーション、環境音、全体BGMを読み込む
- ブラウザのマイクでシーンごとのナレーションを直接録音する
- ナレーションと環境音を別々に音量調整し、環境音の長さをシーンごとに決める
- プロジェクトをJSONで保存・読込する
- Chrome / Edgeで音声入りWebMを書き出す

## 起動方法

Windowsでは `start.bat` をダブルクリックし、ブラウザで `http://localhost:4173` を開きます。

手動で起動する場合は、このフォルダで次を実行してください。

```bash
python -m http.server 4173
```

Pythonランチャーを使うWindows環境では、次でも起動できます。

```bat
py -m http.server 4173
```

依存ライブラリのインストールは不要です。

## v0.2プレビューの使い方

1. 横長画像の端が切れる場合は、右側の「画像の表示」を「全体を表示」にします。
2. 右側の「部分モーション」で「＋ 四角で選ぶ」または「＋ 自由に囲む」を押します。
3. 中央のプレビュー画像で、動かしたい場所をドラッグして囲みます。自由選択では輪郭を一周なぞります。
4. 必要なら「ブラシで足す」「ブラシで消す」で輪郭を微調整します。
5. 「マスクだけ確認」で、白い部分だけが動くことを確かめます。
6. 「動いた跡を周囲の色でぼかして隠す」を必要に応じて切り替えます。
7. 「動き」「動きの強さ」「動きの速さ」を選びます。
8. 「▶ 動きを見る」で確認します。間違えた操作は画面上部の「戻す」で取り消せます。
9. プロジェクトJSONへ保存すると表示方法と選択範囲も保存されます。

## 声を入れる方法

自分の声を使う場合は、対象シーンを開いて「録音開始」を押し、文章を読んでから「停止」を押します。最初だけブラウザからマイク使用の許可を求められます。「端末へ保存」を押すと、録音を後日読み直せる音声ファイルとして残せます。

合成音声や別の録音アプリを使う場合は、「ナレーション音声ファイル」から音声を選びます。ブラウザ音声は声の確認用で、動画へ直接は入りません。録音した声と読み込んだ音声ファイルはWebM書き出しへ入ります。

現在できること:

- `motionRegions` の保存形式
- 画像上の矩形選択と青い編集枠
- 指やマウスで輪郭をなぞる自由選択
- 選択範囲をブラシで追加・削除し、境界をぼかして合成
- 選択範囲だけを白黒で見るマスク確認
- 動いた跡を周囲の色でぼかす簡易背景補完
- 編集操作を最大50段階まで取り消し・やり直し
- 揺れ、移動、波、炎、呼吸に対応するモーション種別
- 選んだ範囲だけのCanvasプレビューとWebM出力
- シーンごとの「画面いっぱい／全体を表示」切り替え
- 入力値の正規化と検証
- 時刻からTransform値を求める純粋関数
- 旧v0.1プロジェクトを読み込むための後方互換方針
- Node標準テストによるデータモデル・座標変換確認

準備コードの確認にはNode.js 20以降で次を実行します。

```bash
npm test
```

詳細は [部分モーション設計](docs/PARTIAL_MOTION.md) と [ロードマップ](docs/ROADMAP.md) を参照してください。

## 現在の制約

- ブラウザTTSは試聴用です。動画へ確実に入れる場合は、マイク録音またはナレーション音声ファイルを使ってください。
- ローカルで追加した画像・音声の本体はプロジェクトJSONへ埋め込みません。
- WebM書き出しは実時間です。2分の作品なら約2分かかります。
- ブラシ修正はベクターの線としてJSONへ保存します。ローカル画像・音声本体は引き続き埋め込みません。
- 背景補完は周囲の色を伸ばしてぼかす簡易方式です。複雑な背景や大きな動きでは不自然さが残るため、将来は手動背景とAI補完を追加します。

## 開発方針

v0.1は動作する基準として維持します。v0.2の計算処理は `src/v0.2/` に分離し、既存UIへ段階的に接続します。次は音声波形による開始・終了位置の調整と、より正確な背景補完へ進みます。
