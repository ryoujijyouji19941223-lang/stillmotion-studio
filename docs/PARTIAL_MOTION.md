# v0.2 部分モーション設計

## 目的

一枚の画像から「木だけ」「カーテンだけ」「水面だけ」のように領域を選び、その領域にだけ小さなループ動作を付ける。元絵、文字、選んでいない部分は固定する。

## 最初に作る最小版

この最小版はv0.2プレビューとして実装済み。

最初の縦切りは次の一往復に限定する。

1. プレビュー上で矩形を一つ選ぶ。
2. `sway` を指定する。
3. プレビューで選択範囲だけが揺れる。
4. JSONへ保存する。
5. JSONを読み直して同じ状態を再現する。

矩形と自由選択は複数追加できる。選択後は追加・削除ブラシで微調整できる。各範囲には名前と独立した `motion` を持たせ、画面の選択欄で一つずつ切り替えて編集する。新しく追加した範囲は `phase` を少しずつずらし、同じ設定でも全範囲が完全に同時に動く見え方を避ける。AI選択とインペイントはこの往復が安定してから足す。

## データモデル

各シーンの `motionRegions` に領域を保存する。領域はマスクと動きの組であり、画像の表示サイズではなく元画像の座標系を基準にする。

```json
{
  "id": "curtain-left",
  "name": "左のカーテン",
  "enabled": true,
  "zIndex": 0,
  "mask": {
    "kind": "rectangle",
    "width": 1080,
    "height": 1440,
    "rect": { "x": 82, "y": 110, "width": 260, "height": 950 },
    "source": null,
    "feather": 8,
    "invert": false
  },
  "motion": {
    "type": "sway",
    "amplitude": 0.25,
    "speed": 0.4,
    "phase": 0,
    "axis": "x",
    "pivot": { "x": 0.5, "y": 0 }
  }
}
```

### マスク種別

| `kind` | 用途 | v0.2内の順番 |
| --- | --- | --- |
| `rectangle` | 最初の動作確認 | 最初 |
| `paint` | 独立した画像マスクを読み込む | 将来 |
| `polygon` | 指やマウスで輪郭をなぞる自由選択 | プレビュー実装済み |
| `ai` | AIが候補を出し人が修正 | v0.3候補 |

現在のブラシ修正は、矩形またはpolygonへ重ねる `mask.strokes` として保存する。各線は `add` / `erase`、太さ、元画像座標の点列を持つ。将来の `paint` と `ai` はマスク画像への相対パスを `source` に保存し、JSONへ巨大なBase64を埋め込まない。

### モーション種別

| `type` | 主な対象 | 基本処理 |
| --- | --- | --- |
| `sway` | 木、草、カーテン | 支点を中心に小さく回転 |
| `drift` | 雲、霧、小物 | X/Y方向へ往復移動 |
| `ripple` | 水面 | 小さなスケール・歪み |
| `flicker` | 炎、照明 | スケールと透明度の揺れ |
| `breathe` | 胸、胴体 | 縦横のごく小さな伸縮 |

共通の `amplitude` と `speed` は0〜1に正規化する。描画時に各モーションの安全な実値へ変換するため、保存データが描画エンジン固有のピクセル量に縛られない。`axis` は左右（`x`）、上下（`y`）、斜め（`both`）を表し、`sway` と `drift` で画面から選択できる。

## 座標と支点

- マスクの `width` / `height` は元画像のピクセル寸法。
- 矩形の `x` / `y` / `width` / `height` も元画像ピクセル。
- `pivot.x` / `pivot.y` は選択領域内の0〜1。
- 画像がCanvasで縮小されても、保存データは変更しない。

## 文字保護

`textLock` は従来どおり画像全体へのカメラ移動を止める。v0.2では別途、動かしてはいけない領域を保護マスクとして持てるようにする。

初期版では、部分モーションと保護マスクが重なった場合に警告して保存を止めない。将来は「保護領域を自動で差し引く」処理を検討する。

## 背景の穴

切り出した前景が動くと、元の位置が見える。この問題は段階的に扱う。

1. 動きを小さく制限する。
2. マスク周辺に余白を持たせる。
3. マスク周囲の色を伸ばしてぼかす簡易背景補完を使う。
4. 手動で背景画像を指定できるようにする。
5. 必要なら自動インペイントを追加する。

自動インペイントが利用できなくても編集できる設計にする。

## エラー時の動作

- 不明なモーション種別: その領域を無効化し、元画像は表示する。
- マスクファイルがない: 警告を表示し、その領域を飛ばす。
- 数値が範囲外: 読込時に安全な範囲へ丸める。
- `motionRegions` がない: 空配列として扱う。
- 一つの領域で失敗: 他の領域とシーン再生は継続する。

## 実装境界

`src/v0.2/partial-motion.mjs` はDOMやCanvasを直接操作しない。データの正規化、検証、時間からTransformを求める処理だけを持つ。これにより、現行Canvas版と将来のRemotion版の両方から同じ規則を利用できる。

UIとCanvas合成は現行の `app.js` へ接続した。データの正規化、座標変換、Transform計算は引き続き独立モジュールに置き、将来の描画エンジンから再利用できるようにする。

## 現在のプレビュー制約

- 矩形と自由選択に対応。追加・削除ブラシと境界ぼかしをプレビュー実装済み。
- 選択範囲だけを白く表示するマスク確認モードを実装済み。
- ブラシ線を一本ずつ選んで編集する機能は未実装。直前の操作は「戻す」で取り消せる。
- 支点は `sway` が下中央、それ以外は中央に自動設定される。
- `sway` は左右なら傾き、上下なら上下移動、斜めなら両方を組み合わせる。
- 背景は周囲の画素を伸ばしてぼかす簡易補完。模様が複雑な背景や大きな移動では違和感が残る。
- 編集用の青い枠は再生中とWebM書き出し中には表示しない。
- 範囲ごとの動き・強さ・速さは独立して保存する。現在編集中の範囲名を設定欄に明示する。

## 最初の受け入れテスト

- v0.1のシーンを正規化すると `motionRegions: []` が追加される。
- 範囲外の強さ・速さ・支点が安全な値へ丸められる。
- 同じ領域と時刻から同じTransformが返る。
- ループ先頭と末尾の見た目が一致する。
- 無効な領域は動かず、描画全体を止めない。
